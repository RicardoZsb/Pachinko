# 弹珠游园会（第 2.1 版）

这是一个活动抽奖用的弹珠小游戏。它有两种形式：

- **Windows 软件 `弹珠游园会.exe`**：单个文件，不用安装，双击就能运行。成绩永久保存在电脑的“文档”文件夹里。
- **网页版 `index.html`**：用浏览器打开就能玩，成绩只保存在当前这个浏览器里。

## 下载与协作

- Windows 玩家可以[下载 Windows 64 位单文件版](https://github.com/RicardoZsb/Pachinko/raw/refs/heads/main/packages/windows-x64/%E5%BC%B9%E7%8F%A0%E6%B8%B8%E5%9B%AD%E4%BC%9A.exe)，保存后双击即可运行。
- 浏览器玩家可以[下载单文件网页版](https://github.com/RicardoZsb/Pachinko/raw/refs/heads/main/index.html)，用浏览器打开即可。
- 开发者可以[下载稳定分支 ZIP](https://github.com/RicardoZsb/Pachinko/archive/refs/heads/main.zip)，或克隆仓库。`main` 保存稳定版本，`develop` 用于日常开发。协作者将测试通过的改动从 `develop` 提交拉取请求，合并到 `main`。
- 任何人都可以下载。需要直接推送改动的协作者，由仓库所有者在 GitHub 的 **Settings → Collaborators** 中邀请，对方接受邀请后即可参与编辑。

## 运行 Windows 软件

1. 双击 `弹珠游园会.exe`。窗口会自动最大化。按 F11，或在“游戏设置”里，可以切换全屏。
2. 第一次运行时，Windows 可能弹出“Windows 已保护你的电脑”。这是因为软件没有数字签名，点击 **更多信息 → 仍要运行** 即可。
3. 软件需要系统里的 **Microsoft Edge WebView2 运行时**。Windows 11 自带，绝大多数 Windows 10 也已经通过系统更新装好了。如果打不开，去微软官网搜索“WebView2 Runtime”，下载并安装 Evergreen 版本即可。
4. 软件把页面资源都打包在 exe 里面，不需要联网，字体也已经内置。

## 存档（开始界面的“存档”按钮）

**保存位置**：每局结束会立即写入 `文档\弹珠游园会\`，关掉软件、重启电脑都不会丢。

| 文件 | 内容 |
| --- | --- |
| `存档.json` | 完整存档。包括每个榜单的全部玩家（名次、昵称、邮箱、最高分、时间、游玩次数），按得分从高到低排列；也包括活动参数和游戏设置 |
| `排行榜.csv` | 同样的榜单，可以直接用 Excel 打开。列依次为：名次、昵称、邮箱、最高分、游玩次数、最高分时间、地图、规则版本 |
| `存档.上次启动备份.json` | 本次启动后第一次保存前，会把上一次的存档复制一份放在这里，防止误删 |

**存档界面能做的事**：

- 按榜单查看所有玩家的昵称、完整邮箱和最高分，按最高分从高到低排列。
- 按昵称或邮箱搜索。
- 删除单条成绩：点“删除”，再点一次“确认删除”。
- 清空整个榜单：同样需要再点一次确认。
- 导出 CSV。
- 在软件里一键打开存档文件夹。

**榜单的规则**：

- 同一个“邮箱＋昵称”只保留最高分。
- 同分时，先达到这个分数的人排在前面。
- 主界面的公开排行榜会把邮箱部分打码，存档界面显示完整邮箱。

**换电脑时**：把 `文档\弹珠游园会` 文件夹整个复制过去，就能保留全部成绩。

**网页版**：成绩保存在浏览器的本地存储里，清除浏览器数据就会丢失。可以用存档界面的“导出表格（CSV）”另存一份。

## 这一版的改动

- **自动拨杆加长约 1/3**：长度从 140 改为 187。转轴略微下移，上摆角度收小了一点，拨杆扫过时不会碰到最下面一排道具。拨杆变长后接住的球更多，所以 A 图的目标分从 6,000 调到了 7,000。
- **新增存档**：开始界面多了“存档”按钮，见上一节。
- **Windows 软件**：基于 Neutralinojs 运行时，exe 约 4.7 MB。

## 文件

| 文件 | 用途 |
| --- | --- |
| `packages/windows-x64/弹珠游园会.exe` | 经确认的 Windows 64 位成品，发布版本时原样上传 |
| `index.html` | 网页版成品 |
| `src/core.js` | 规则和物理：道具、地图、自动拨杆、计分。不依赖网页，可以单独在 Node 里运行 |
| `src/render.js` | 画面 |
| `src/audio.js` | 用 Web Audio 实时合成的音乐和音效 |
| `src/store.js` | 存档：软件里读写文件，网页里读写浏览器本地存储 |
| `src/ui.js` | 各个界面、操作输入、存档界面、活动参数、主循环 |
| `src/style.css`、`src/body.html` | 界面样式和页面结构 |
| `tools/sim.js` | 批量模拟对局，用来校准通关分 |
| `tools/win/` | Windows 打包工具：`patch-exe.cjs`（替换图标、写入版本信息、内嵌资源）、图标文件 |
| `vendor/` | Neutralinojs 6.9.0 的 Windows 运行时和客户端库、两套字体，以及各自的许可证 |

## 重新生成

需要 Python 3 和 Node.js。

```
python build.py          # 只生成网页版：dist/index.html
python build.py --app    # 同时生成 Windows 软件：dist/弹珠游园会.exe
```

`--app` 会做三件事：

1. 把页面、字体和图标打成 `resources.neu`。
2. 用 `tools/win/patch-exe.cjs` 把它嵌进 `vendor/neutralino-win_x64.exe`，同时换上图标和版本信息。
3. 输出单文件 exe。

发布新版本时，在 `main` 上确认 `build.py` 的版本号，将验收后的 EXE 放入 `packages/windows-x64/`，并更新根目录的 `index.html`。在 GitHub Releases 为稳定提交创建版本标签（例如 `v2.1.0`），将这两个文件分别以 `Pachinko-Windows-x64.exe` 和 `Pachinko-Web.html` 为名上传。
